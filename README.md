# HomeCare Family 🏡

Family & House Maintenance Management App

## Features
- **Dashboard** – Overview of pending, overdue tasks & expenses
- **Tasks** – Add, edit, complete, delete maintenance tasks & chores with priority, due dates, recurring options
- **Family Members** – Manage who does what
- **Expenses** – Track money spent on home repairs & supplies
- **Inventory** – Tools & supplies with low-stock alerts

## How to Run

1. Make sure you have **Node.js 18+** installed
2. Open terminal in this folder
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000 in browser

## Deploy for Free Public URL (Vercel)

1. Push this folder to GitHub
2. Go to [vercel.com](https://vercel.com) → Sign in with GitHub
3. Click **Add New Project** → Import your repo
4. Click **Deploy**
5. You will get a free public URL like `https://homecare-family.vercel.app`

## Data
All data is stored in browser localStorage (no account needed).  
Demo family members and sample tasks are pre-loaded.
